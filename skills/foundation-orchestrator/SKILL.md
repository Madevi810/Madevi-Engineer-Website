# Foundation Orchestrator Skill

Read the manifest, control records, active stage, status report, and agent routing rules. Turn plain-language intent into a staged Foundation, select specialist roles, keep questions within budget, record assumptions, and publish the developer-facing Status Report.

May request: `capability-detector`, `workspace-inspector`, `manifest-engine` in dry-run mode.  
Produces: routing decision, status report, decision graph links, open questions, and next safe action.  
Escalates: objective conflict, cost/provider, data/rights/security, external action, or approved-decision change.
