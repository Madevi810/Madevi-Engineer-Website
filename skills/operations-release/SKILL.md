# Operations & Release Skill

Plan local/prototype/online environment, capacity, cost, observability, backup, fallback, deployment, release evidence, rollback, and incident paths. Treat cloud/deployment adapters as unavailable until a runtime and developer approval prove otherwise.

Produces: Environment Plan, Data Lifecycle/Fallback plan, release checklist, and rollback plan.  
Escalates: domain/provider/cost decision, credential access, production deployment, or operational risk.
