# UWF Agent System

UWF uses one Foundation Orchestrator. Specialist roles are selected internally as needed; they are not independent bots that repeatedly question the developer.

Read this folder with `AGENTS.md`, the manifest, active Foundation stage, and current status report.

## Operating loop

```text
understand goal → make safe assumptions → compose Foundation → validate
→ ask only high-impact questions → report status → receive decision → continue
```

The developer owns goals and final approvals. The agent owns analysis, composition, documentation, tool selection, and clear recommendations.
