# Status Protocol

Every material stage ends with this compact developer-facing report:

```text
Stage:
Status: DRAFT | ANALYZING | NEED_INFO | WARNING | CONFLICT | READY | APPROVED | COMPLETE
Goal understood:
What the agent designed:
Assumptions:
Roles/materials/tools used:
Risks or limits:
Questions for developer (0–3):
Recommendation:
Developer options:
Next safe action:
```

Put the current report in `Foundation/00-Control/Status-Report.md`. Put every executed local tool action in `Action-Journal.md`.
