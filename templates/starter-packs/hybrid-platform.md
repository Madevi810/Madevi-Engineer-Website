# Starter Pack — Hybrid Platform

Use when one web product combines multiple modules such as articles, marketplace, community, games, or media.

## Suggested Foundation focus

- Shared identity, roles, navigation, design system, data boundaries, API ownership, moderation, and operations
- MVP order: identify which module launches first and which modules remain planned or deferred
- Cross-module privacy, performance, analytics, notification, and support concerns

## Initial feature-gap prompts

- What shared user account, navigation, and design rules are needed?
- Which module is required for v1, and which must not block it?
- Where can data, permissions, payments, or moderation cross module boundaries?
