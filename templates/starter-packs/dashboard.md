# Starter Pack — Dashboard

Use for internal operations, analytics, admin panels, or SaaS workspaces.

## Suggested Foundation focus

- Primary user roles, permissions, data sources, KPIs, filters, export policy, audit trails, and operational alerts
- Desktop and mobile task priority, keyboard access, dense-data readability, empty/error/loading states, and accessibility
- Security boundaries, retention, privacy, and rollback for destructive actions

## Initial feature-gap prompts

- Which decisions must users make from this dashboard?
- What data may be exported, edited, or deleted, and by whom?
- What is the safe fallback when data is delayed, incomplete, or wrong?
