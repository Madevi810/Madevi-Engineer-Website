# Stage 03 — Project Mode

Choose one current mode:

1. **Prototype local** — learning, experimentation, or a device-only demo.
2. **Prototype online** — a shareable demo link with test data.
3. **Beta** — limited real users, controlled feedback, and stronger safeguards.
4. **Production online** — public/real-user operation with security, operations, and recovery requirements.

The current mode changes recommendations. A local prototype should not be forced to use a domain, paid cloud, real payment gateway, online authentication, or production database. Record what is intentionally simulated and its future migration path.
