# Stage 05 — Features and Requirements

Write a feature specification before implementation. Include:

- problem and intended user;
- business rule and user flow;
- acceptance criteria;
- dependencies and data impacts;
- UX states: loading, empty, success, error, permission denied;
- security and privacy implications;
- test strategy;
- stage priority.

Use `templates/feature-spec.md`.

Run `Feature-Gap-Audit.md` at major stage boundaries, before implementation approval, before release, and after a material change. It turns likely missing requirements into reviewable suggestions; it does not silently add scope.
