# External Reference & Evidence

External research fills verified gaps; it never replaces judgement or creates permission to copy.

## Reference types

| Type | Use | Required handling |
| --- | --- | --- |
| Engineering dependency | Library, framework, SDK, service | License, health, security, compatibility, lock-in and exit review |
| Official factual source | Government, standards body, original publisher, primary research | Date, claim, scope, and citation review |
| Design inspiration | Product/site/repository visual behavior | Clean-room analysis; no copied identity or distinctive composition |
| Creative source | Book, video, image, audio, game, social post | Rights, attribution, transformative/original plan, permitted use |
| Trend/discovery source | Community or social media signal | Treat as a lead, not proof, until verified |

Use Source-Policy before search. Record reviewed sources in Evidence-Registry and create a separate Evidence Card for material decisions.
