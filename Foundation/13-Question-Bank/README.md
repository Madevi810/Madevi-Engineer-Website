# Foundation Question Bank

The Question Bank is a progressive interview system, not a form that must be completed in one sitting. The agent selects only the questions needed for the active Foundation stage and project mode.

Every question must provide:

- a plain-language reason;
- an agent recommendation when the developer is unsure;
- concise choices first;
- a full choice list when requested;
- a custom-answer option;
- an impact note when the decision affects later stages.

## Pack selection

1. Start with Developer-Levels.
2. Use Core-Foundation through all projects.
3. Add exactly one Project-Modes pack for the current mode.
4. Add one or more module packs for active modules.
5. Add Autonomous-Operations only when automation is requested.

Never block the complete Foundation because a future module has unanswered questions. Mark it DEFERRED instead.
