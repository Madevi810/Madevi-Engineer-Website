# Project Mode Questions

## Prototype local

- Which device and local environment will run the prototype?
- Can mock data, demo accounts, and test payment be used?
- Which features must be visible now, even if simulated?
- What event will trigger an online upgrade?

## Prototype online

- Who may access the demo link?
- How long should the preview exist?
- Are test data and public sharing acceptable?
- Is a temporary database or file store required?

## Beta

- Which users are invited?
- How will feedback and bugs be collected?
- What data is real, and what remains test data?
- What rollback path exists?

## Production online

- Are real accounts, payments, files, or personal data involved?
- Which domain, database, hosting, backup, monitoring, and support requirements apply?
- What is the monthly cost ceiling?
- What is the launch, rollback, and incident process?
