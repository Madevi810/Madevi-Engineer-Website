# Developer Level Questions

## Beginner

- What kind of web project do you want to make?
- Who will use it?
- Is it only a practice/demo project or will real people use it?
- Do you want the agent to recommend the easiest path?
- What device do you have for development: Android/Termux, laptop, or desktop?
- Do you have a budget now, later, or no budget?

Agent behavior: use short explanations, show two or three safe choices, defer advanced provider choices, and explain unfamiliar terms.

## Intermediate

- Which technologies do you already know?
- Which decisions do you want agent recommendations for?
- Do you need flexibility for future modules?
- What are your time and operating-cost constraints?

Agent behavior: show alternatives, compatibility notes, and migration costs.

## Professional

- What architecture constraints, standards, or existing systems apply?
- Which operational and compliance requirements are mandatory?
- What deployment, observability, and ownership model is required?
- Which custom stack components are non-negotiable?

Agent behavior: retain full detail, record explicit trade-offs, and never simplify a declared professional constraint without approval.
