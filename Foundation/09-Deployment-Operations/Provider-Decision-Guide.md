# Provider Decision Guide

Choose provider class before provider brand.

| Class | Suitable for | Typical trade-off |
| --- | --- | --- |
| Local/free | Learning and local prototype | No public reliability or real-user safeguards |
| Economical managed | MVP and low-traffic public web | Provider limits and usage pricing |
| Moderate managed/cloud | Growing applications | More services and operational cost |
| Professional cloud/VPS | Business-critical and complex platforms | Requires stronger operations capability |

The agent must verify current provider prices and regional availability when a developer asks for a specific provider recommendation. Static documentation must not claim current prices.
