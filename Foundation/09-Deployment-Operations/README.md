# Stage 09 — Deployment and Operations

For each current mode, explain what is required now and what can be deferred.

| Mode | Typical approach |
| --- | --- |
| Local prototype | Local environment, dummy data, local/test database |
| Online prototype | Preview host, test services, temporary data policy |
| Beta | Staging-like environment, feedback route, backup/testing plan |
| Production | Domain/SSL, secure database, backups, monitoring, incident/runbook |

Give provider recommendations in cost classes—free/local, economical, moderate, professional—unless the developer explicitly requests current provider prices. Provider pricing must be verified at recommendation time, not stored as permanent fact.
