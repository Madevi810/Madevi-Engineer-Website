# Research, Content & Production Operations

This area activates only when the developer asks UWF to plan, create, maintain, or publish project content such as articles, product catalogs, lessons, games, animation/video, media, or community material.

It turns plain-language intent into an original, reviewable production system:

```text
intent → taxonomy → source plan → content map → batch plan → draft/assets
       → quality and rights review → developer approval → implementation/publish queue
```

Default state is `plan_only`. Searching, drafting, writing project files, scheduling, and publishing are separate actions. A working web-search tool is not assumed; record availability in `agent_runtime` first.

Read `Research-Policy.md`, `Taxonomy-Content-Map.md`, `Scale-Batch-Plan.md`, and `Publish-Controls.md` before running content work.
