# Stage 02 — Objectives and Product Direction

Capture one or many objectives. Mixed platforms are valid: for example, an article site with marketplace, web game, animation, community, and dashboard modules.

For each objective record:

- target users and their problem;
- intended outcome and measurable success signal;
- priority: now, next, later, or archive;
- dependencies on shared services;
- what is explicitly out of scope for the current phase.

Completion criteria:

- A primary objective exists.
- Current MVP modules are prioritized.
- Success metrics or validation signals exist.
- Scope conflicts are recorded.
