# Developer Onboarding Questionnaire

## 1. Experience level

Choose one:

- [ ] Beginner — simple language, limited initial choices, quick safe path.
- [ ] Intermediate — practical options, explanations, and trade-offs.
- [ ] Professional — complete detail, custom architecture, and operational analysis.

## 2. Guidance mode

Choose one:

- [ ] Full agent recommendation — agent proposes the best-fit Foundation; developer reviews and approves.
- [ ] Recommendation with complete list/custom choice — agent recommends, developer may select any catalog entry or write a custom answer.

## 3. Working preference

- [ ] I want to implement an approved stage early.
- [ ] I prefer completing more Foundation stages before implementation.
- [ ] I am not sure; recommend a path.

The agent must record answers in the manifest and Decision Log before moving to objectives.
