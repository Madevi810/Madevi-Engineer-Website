# Foundation Map

The Foundation is the planning and control layer. It contains no application implementation.

| Area | Purpose |
| --- | --- |
| `00-Control` | Questions, assumptions, decisions, risks, changes, and reports |
| `01-Developer-Profile` | Experience level and guidance mode |
| `02-Project-Objectives` | Multi-objective product direction, users, and success metrics |
| `03-Project-Mode` | Local prototype, online prototype, beta, or production |
| `04-Product-Modules` | Article, commerce, game, video, community, and other modules |
| `05-Features-Requirements` | MVP, feature specs, acceptance criteria, dependencies |
| `06-UX-UI` | Information architecture, flows, design, accessibility |
| `07-Architecture` | Stack catalog, compatibility, data/API/auth recommendations |
| `08-Quality-Security` | Testing, performance, quality, rights, privacy, security |
| `09-Deployment-Operations` | Local setup, hosting, database, cloud, costs, monitoring |
| `10-Upgrade-Migration` | Prototype-to-online and Foundation version migrations |
| `11-Autonomous-Operations` | Optional scheduled/automated work policies |
| `12-Handover` | Approved implementation package and implementation feedback |
| `13-Question-Bank` | Progressive question packs by developer level, project mode, and module |
| `Archive` | Immutable snapshots of replaced/previous Foundation versions |

Complete the stages progressively. The developer may implement an approved stage or continue answering the next Foundation stage.
