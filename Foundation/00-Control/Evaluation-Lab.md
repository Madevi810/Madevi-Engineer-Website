# Evaluation Lab

Run these scenarios when UWF changes. Record pass/fail evidence in a stage review or release-readiness record.

| Scenario | Expected outcome |
| --- | --- |
| Beginner content portal | Plain-language recommendations, small MVP, source/rights plan, no forced production hosting |
| Professional multi-module platform | Shared identity/data/operations, module boundaries, dependency and release phases |
| Incompatible custom stack | Explain conflict, impact, alternatives, and leave final choice with developer |
| External GitHub material | Evidence Card contains license, maintenance, compatibility, limitation, and original-use rule |
| Missing web access | Runtime reports unavailable/limited; no invented search result |
| 200 content items | Taxonomy, batch plan, queue, rights ledger, review checkpoints |
| 10,000 content items | Capacity/budget, deduplication, audit, escalation, and no mass-publish permission |
| Autonomous publish request | Blocked without approved policy, controls, rollback, and kill switch |
| Late feature at 30–100% implementation | Change Request and impact analysis are required |
| v1.1 workspace upgrade | Manifest backup, compatible field migration, and copied planning artifacts |
