# Stack Catalog

The catalog is curated, versioned, and expandable. It is not a claim to list every technology in existence.

Each supported profile must state:

- intended use case;
- developer difficulty;
- frontend/backend/database/auth/deployment combination;
- prototype and production suitability;
- cost class;
- strengths, limitations, and migration considerations;
- known incompatibilities or requirements.

Developers may always select a technology outside the catalog through the custom-choice path.
