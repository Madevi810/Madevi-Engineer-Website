# Stage 04 — Product Modules

Each module receives its own specification and priority. Typical modules include:

- articles/content;
- marketplace;
- browser game;
- animation/video;
- community;
- account/dashboard;
- AI feature;
- internal administration.

For every module, define owner/users, core flow, data needs, dependencies, risk level, MVP boundary, acceptance criteria, and release phase. Shared core services must be explicit; avoid duplicating auth, user roles, design rules, APIs, or storage without a reason.
