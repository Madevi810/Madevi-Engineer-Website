# Online Upgrade Questions

- Does the original objective remain the same?
- Which prototype features become real-user features?
- Are accounts, personal data, payment, uploads, or external APIs now required?
- What test data must be discarded, migrated, or anonymized?
- What domain, SSL, database, storage, backup, monitoring, and support requirements apply?
- What budget and monthly limit apply?
- Is downtime acceptable, and what rollback is required?
- Which provider decisions are still deferred?

The agent must compare prototype assumptions with the target online plan before implementation begins.
