# Stage 10 — Upgrade and Migration

Use this stage for prototype-to-online changes, major stack shifts, and UWF schema upgrades.

Required sequence:

1. Snapshot the current approved Foundation.
2. Keep original product objectives visible.
3. Ask upgrade-specific questions.
4. Compare current state with target state.
5. Identify gaps, data migration needs, cost/security impact, downtime, rollback, and validation.
6. Produce a migration plan and require developer approval.
7. Archive the previous Foundation as a reference.

Use `templates/migration-plan.md`.
