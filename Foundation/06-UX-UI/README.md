# Stage 06 — UX/UI

Define sitemap, navigation, user flows, responsive behavior, accessibility, design system, empty/error/loading states, and content voice. Design recommendations must fit the actual user and product objective rather than default visual trends.

Start with `Creative-Brief.md`. It is optional: use the developer's own visual direction when present; otherwise provide objective-based recommendations, complete choices on request, and a custom-answer option.

Agree on layout and hierarchy first, then colors, typography, effects, motion, and visual density. Complete `Responsive-Accessibility-Review.md` before generating a mockup or prototype. `Simulation-Plan.md` records whether the developer wants an image mockup, responsive HTML prototype, both, or neither. All simulations remain planning drafts until approved.
